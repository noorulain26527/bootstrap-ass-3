# Corona Virus Website

A responsive frontend website created using Bootstrap, HTML5, and CSS3. This project focuses on practicing Bootstrap components, responsive layouts, and modern website styling.

## 🚀 Features

- Responsive Bootstrap Navbar
- Hero Section
- Bootstrap Cards
- Image Sections
- Buttons
- Responsive Grid System
- Bootstrap Utility Classes
- Clean and Modern Layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
